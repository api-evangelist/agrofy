# Agrofy

> Agrofy is a Latin American agribusiness technology company founded in 2015 in Rosario,
> Argentina. It operates the region's largest online marketplace for agricultural inputs,
> machinery, farmland, vehicles and services (Agrofy Market), an agricultural news
> publication (Agrofy News), and payments, credit and financing for agribusiness
> transactions (Agrofy Pay). Agrofy markets a seller integration program, Agrofy
> Developers, but publishes no machine-readable API contract.

Generated by API Evangelist from the public Agrofy surface on 2026-09-13. This is an
independent third-party profile; it is not published by Agrofy. Every link below was
fetched and returned HTTP 200 on that date unless noted.

## API surface

- [Agrofy Developers](https://developers.agrofy.com/): The company's partner-integration
  program for marketplace sellers — listing management, lead management and catalog
  synchronisation. The page is a static brochure. Its onboarding is a contact form: an
  Agrofy advisor provisions the account before a reference guide is shared.
- [Agrofy API gateway](https://apigateway-argentina.agrofy.com): The first-party AWS API
  Gateway the Argentine marketplace front end calls, observed in the markup of
  www.agrofy.com.ar. `GET /api/main-menu/list` returns HTTP 200 `application/json`
  unauthenticated; every unmapped route returns `403 {"message":"Missing Authentication
  Token"}`. Agrofy publishes no contract describing it.

## What is NOT published

No OpenAPI, Swagger, GraphQL SDL, AsyncAPI, Protobuf or WSDL was found on any Agrofy host.
No `/.well-known/` document is served on any Agrofy host. No MCP server, no A2A agent card,
no `llms.txt`, no status page, no changelog, no public rate limits, no public API pricing,
and no first-party SDK in npm, PyPI, RubyGems or crates.io. The eight per-country API-doc
links on developers.agrofy.com — developers.agrofy.com.ar/docs, .com.bo, .com.br, .cl,
.com.co, .com.py, .com.pe, .com.uy — do not resolve: three are dangling CNAMEs pointing at
NXDOMAIN targets under `route53.prod-us-1.eks.agrofy.com`, and five have no DNS record.
